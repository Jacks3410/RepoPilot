# Upstream attribution

RepoPilot started as an extension of the open-source
[Learn-OpenClaw](https://github.com/lasywolf/Learn-OpenClaw) tutorial by
`lasywolf`, distributed under the MIT License.

The tutorial supplied the initial learning scaffold. RepoPilot's repository
agent, security controls, approval gates, verification loop, checkpoints,
auditing, evaluation suite, dashboard, packaging, container delivery and CI
were developed as the portfolio project in this repository.

The original tutorial material remains available from the upstream project;
it is intentionally not duplicated here so this repository stays focused on
the production-oriented RepoPilot implementation.
